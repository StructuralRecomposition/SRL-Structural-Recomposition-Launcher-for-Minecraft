# SRL v0.1.1 — 界面重构

这一版不是功能扩张，而是一次完整的界面与交互整理。所有既有能力保留，视觉语言改为更安静、更结构化的中性色体系。

## 界面

- 移除紫绿渐变、背景光晕、彩色投影与过度圆角，改用平面面板、单一信号色与清晰层级。
- 侧栏改为「游戏 / 工具 / 系统」三段式导航，当前页使用实心信号色标记。
- 顶栏、卡片、按钮、输入框、标签、进度条、弹窗与提示统一尺寸、圆角与字重。
- 首页启动面板改为顶部细强调线的平面结构，实例、账号、Java 与文件状态更易扫读。
- 深色主题保持中性黑灰；浅色主题改为暖白纸面。两套主题使用同一套语义色。

## 动画

- 页面入场、列表错落、导航滑入、卡片悬浮、弹窗与提示出现、进度流光、空状态浮动。
- 全部动画遵循 `prefers-reduced-motion`，系统开启减少动态效果时自动关闭。

## 功能

- 版本安装、加载器、资源搜索、实例管理、Java、任务、账号、皮肤、诊断与鸦鸭助手入口全部保留。
- 不改变后端命令、数据目录、实例格式或账号数据。
- 兼容已有设置、实例与本地数据。

## 安装包

- macOS：`SRL_0.1.1_universal.dmg`（Intel + Apple Silicon）。
- Windows：`SRL_0.1.1_windows-x64-portable.zip`（x64 便携版）。
- Linux：`SRL_0.1.1_amd64.deb` 与 `SRL_0.1.1_amd64.AppImage`（x64）。
- 校验值见同目录 `SHA256SUMS`。
