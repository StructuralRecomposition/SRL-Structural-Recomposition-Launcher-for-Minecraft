# SRL v0.2.0 — Minecraft 联机中心

SRL 现在可以直接创建 Minecraft 联机房间，不要求公网 IP、路由器端口映射或 FRP 知识。朋友不用开穿透，直接连接房主复制出来的公网地址即可。

## 主要更新

- 新增「Minecraft 联机」页面：账户、实例、版本类型、本地服务、节点、房间与 FRPC 状态集中在一页。
- 使用 52FRP 开放 API v1：账户、节点、节点负载、名称/端口检查、已占用端口、隧道创建/查询/删除、完整 FRPC TOML。
- Java Edition 使用 TCP，自动识别局域网动态端口；Bedrock Edition 使用 UDP，支持 19132 与手动端口。
- 创建过程展示真实检查结果；失败自动回滚隧道与 FRPC；停止联机与删除临时隧道分离。
- API 令牌只保存在系统凭据库；FRPC 配置使用 0600 临时文件，停止时删除。
- FRPC 使用 fatedier/frp 官方 Release，按 SHA-256 校验；缓存优先、国内镜像优先、连接后后台预下载，界面显示下载进度。
- 联机页重新整理为「账户 / 创建房间 / 当前状态」三块，减少说明文字；字段解释收进 `?`，提示浮层固定在顶层，不会被卡片或弹窗遮挡。
- 「当前状态」旁新增「帮助」：从 52FRP 注册、实名认证、套餐商城、头像 → API 访问、创建令牌权限，到房主开世界、朋友直连、离线联机模组和常见错误。
- 设置与账号管理页压缩冗余说明；账号卡只保留名称、类型、状态与操作。
- 鸦鸭导航与页面标题增加「测试」标签。

## Microsoft 正版登录

很抱歉，受当前开发条件限制，SRL 还不能做到开箱即用的 Microsoft 正版登录。目前需要自行注册 Azure 应用、获取 `client id` 并在设置中填写；未配置时登录入口会明确禁用。后续版本会继续修复，感谢理解。

## 安装包

- macOS：`SRL_0.2.0_universal.dmg`
- Windows x64：`SRL_0.2.0_windows-x64-portable.zip`
- Linux x64：`SRL_0.2.0_amd64.deb`、`SRL_0.2.0_amd64.AppImage`
- 校验：`SHA256SUMS`

安装包不包含账号、实例、皮肤库、日志或缓存。首次启动会创建干净的应用数据目录。

## 连接 52FRP

1. 登录 <https://www.52frp.com/user/#/user-center>，完成注册与实名认证。
2. 在套餐商城选择节点并购买套餐（常见价格约 4.5 元/月，以商城为准）。
3. 点右上角头像 → API 访问 → 创建令牌，权限勾选「创建和修改隧道与客户端」，复制 `hz_` 开头的令牌。
4. 打开 SRL →「Minecraft 联机」，粘贴令牌并连接。

## 已知限制

- 需要真实 52FRP 账户与令牌完成在线联调；没有令牌无法伪造测试成功。
- 账户必须实名，且套餐覆盖目标节点。
- Bedrock 需要本机已有 UDP 服务监听。
- Microsoft 登录仍需自行配置 Azure client id；这是当前版本的主要体验缺口。
