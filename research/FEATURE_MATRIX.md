## 阶段 1 实际验证补充

- `cargo test -p sr-core`：100 项库测试 + 2 项启动集成测试全部通过（网络测试默认忽略）。
- Microsoft 登录：设备码、令牌交换、刷新、未配置错误均通过模拟 HTTP 服务测试；未使用真实账号。
- 实例导出/导入：往返、路径穿越、重复路径、缺失清单、未安装版本、符号链接 6 类测试通过。
- 断点续传：206 + If-Range、服务器忽略 Range 回退 200、无验证器不续传三种场景通过。
- `cargo test -p sr-core --test real_install -- --ignored`：真实安装 Minecraft 1.12.2（不含 assets），37 个核心文件校验通过，natives 成功解压。
- `npx vitest run`：11 项前端测试通过。
- `npx tauri build --debug --no-bundle`：生成 macOS 可执行文件。
- 应用实际启动：Java 扫描发现 3 个环境，数据目录与日志正常创建。
- 未验证：Windows/Linux 构建、真实 Microsoft 登录、真实 Minecraft 进程启动（缺 Java 8 与正版账号）、GUI 截图（macOS 辅助访问权限受限）。
