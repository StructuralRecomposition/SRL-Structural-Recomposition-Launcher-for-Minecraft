# 架构决策记录（ADR）

格式：编号 / 决策 / 背景 / 备选方案 / 结论 / 后果 / 状态

## ADR-001 桌面框架：Tauri 2

- **背景**：需要 Windows/macOS/Linux 三平台桌面应用，安装包小，前端迭代快，后端需强类型与原生进程控制。
- **备选**：Electron（体积大、Node 进程权限面大）、纯 Rust GUI（egui/iced，UI 生态弱）、Flutter（Rust 集成成本高）。
- **结论**：Tauri 2 + 系统 WebView。Rust 承担全部文件、网络、进程、凭据逻辑；前端只做展示与交互。
- **后果**：需要处理 WebView 差异；Tauri ACL 必须最小化；跨平台构建依赖各自系统工具链。
- **状态**：已采纳。

## ADR-002 前后端边界：命令式 IPC，而非前端直连网络

- **背景**：Minecraft 安装涉及并发下载、哈希校验、路径安全与进程管理，前端不适合承担。
- **备选**：前端直接 fetch 元数据（简单但无法安全落盘/校验/限流）；本地 sidecar HTTP 服务（多一层攻击面）。
- **结论**：前端仅调用 `#[tauri::command]`，所有输入在 Rust 侧校验；下载与启动完全在后端。
- **后果**：命令需稳定的 DTO 与错误码；事件用于进度推送。
- **状态**：已采纳。

## ADR-003 数据存储：JSON 配置 + 未来 SQLite

- **背景**：阶段 1 数据量小（设置、实例、账号档案、任务快照）。SQLite 会引入迁移与并发复杂度。
- **结论**：JSON + 原子写入（临时文件 + fsync + rename）。仅在出现大量可查询历史（如安装记录、模组索引）时引入 SQLite。
- **后果**：并发写需单写者锁；文件损坏需备份恢复。
- **状态**：已采纳。

## ADR-004 下载引擎：自研任务层 + reqwest

- **背景**：需要并发上限、取消、重试退避、SHA-1 校验、原子落盘、进度聚合。
- **备选**：直接 `reqwest` 逐文件（无统一取消/进度）；引入通用下载库（可控性不足）。
- **结论**：`DownloadManager` 管理任务与取消令牌，`download_one` 负责单文件；信号量限流；临时文件 `.srpart`；成功后 rename。
- **后果**：需自行保证同目标文件不并发写（任务内串行 + 全局目标锁）。
- **状态**：已采纳。

## ADR-005 版本模型：直接映射官方 JSON，不引入中间 DSL

- **背景**：Minecraft 版本格式随年代变化（`minecraftArguments` vs `arguments`、inheritsFrom、natives）。
- **结论**：建模为宽松结构（未知字段忽略、可选字段显式），解析后做规范化；继承在 `resolve` 阶段合并。
- **后果**：需真实夹具覆盖新旧格式；禁止假设字段恒存在。
- **状态**：已采纳。

## ADR-006 账号：离线档案立即可用，Microsoft 登录需显式配置

- **背景**：无 Azure 应用注册凭据，无法完成真实 OAuth；伪造登录违反安全要求。
- **结论**：实现 `AccountStore` 与离线档案；Microsoft 登录返回明确的 `NotConfigured` 错误并展示配置说明；令牌存储抽象为 `SecretStore`（keyring），当前不写入真实令牌。
- **后果**：正版登录在配置 client id 前不可用；UI 必须如实标注。
- **状态**：已采纳。

## ADR-007 启动：参数数组 + 占位符白名单

- **背景**：字符串拼接会导致引号/空格注入与跨平台错误。
- **结论**：`Command::new(java).args(Vec<String>)`；占位符仅替换已知键；未知占位符保留并记录警告；令牌不写入日志。
- **后果**：Windows 超长命令行需未来处理（当前记录限制）。
- **状态**：已采纳。

## ADR-008 安全边界：默认拒绝

- **结论**：
  - 下载 URL 仅允许 Mojang 官方域名（可配置镜像需显式开启并记录）。
  - 所有相对路径经 `safe_join`。
  - Tauri 不启用 shell/fs 插件；CSP 限制脚本来源。
  - 更新模块在未配置公钥时禁用，不做"仅哈希"验证。
- **后果**：灵活性下降，安全性上升；镜像/更新需后续显式设计。
- **状态**：已采纳。

## ADR-009 前端技术：React + TypeScript + Vite，无重型状态库

- **背景**：阶段 1 状态规模可控；引入 Redux/Zustand 会增加依赖与样板。
- **结论**：React 19 + 自研 hooks（`useAsync`、`useTasks`）+ 事件订阅；后续复杂度上升再评估。
- **后果**：跨页共享状态需提升到 App 层；避免 prop drilling 过度。
- **状态**：已采纳。

## ADR-010 许可策略：独立实现，MIT

- **背景**：PCL2 为限制性自有许可；HMCL 为 GPL-3.0；HMCL 文档为 CC BY-NC-SA 4.0。
- **结论**：不复制任何参考项目代码/文档/素材；SR Launcher 以 MIT 发布自己的代码。Minecraft 游戏文件不随项目分发。
- **后果**：不能直接借用 GPL 实现；所有功能需按官方规范独立实现并测试。
- **状态**：已采纳。
