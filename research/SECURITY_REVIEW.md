# 安全评审与威胁模型

版本：阶段 1。范围：本地桌面启动器（Tauri 2 + Rust + React）。

## 1. 资产

1. 用户 Microsoft/Minecraft 令牌与账号档案。
2. 本地游戏文件与实例数据（存档、配置、模组）。
3. 应用更新包的完整性与来源。
4. 用户磁盘上的其他文件（路径穿越/覆盖风险）。
5. 日志与诊断报告中的隐私信息。

## 2. 信任边界

```
[React WebView] --IPC--> [Rust 后端] --HTTPS--> [Mojang 官方源]
                               |--> [本地文件系统]
                               |--> [Java 子进程]
                               |--> [系统凭据库]
```

- WebView 视为**不可信输入源**：所有命令参数必须校验。
- 下载内容视为**不可信**：必须校验哈希、限制路径、限制大小。
- 版本 JSON 视为**不可信**：URL 白名单、路径清洗、循环继承检测。
- Java 子进程输出视为**不可信文本**：仅显示/落盘，不执行。

## 3. 威胁与缓解

| ID | 威胁 | 影响 | 缓解 | 状态 |
|---|---|---|---|---|
| T-01 | 恶意版本元数据指向任意 URL | 下载恶意文件/SSRF | URL scheme 仅 https；域名白名单；重定向后再校验 | 已实现 |
| T-02 | 元数据路径 `../../` 穿越 | 覆盖系统文件 | `safe_join` 拒绝绝对路径、`..`、盘符、空段 | 已实现 |
| T-03 | 下载文件被篡改 | 执行恶意 JAR | 强制 SHA-1 比对（官方提供时）；失败即删除临时文件 | 已实现 |
| T-04 | 并发写同一文件损坏 | 文件损坏/启动失败 | 单任务串行 + 目标路径互斥；临时文件唯一命名 | 已实现 |
| T-05 | 令牌泄露到日志 | 账号被盗 | 启动参数不整体记录；日志脱敏函数过滤 `accessToken` 等键 | 已实现 |
| T-06 | 前端调用任意系统命令 | 远程代码执行 | 不启用 shell 插件；不暴露通用 exec 命令 | 已实现 |
| T-07 | XSS 通过版本描述注入 | 会话劫持 | React 默认转义；CSP 禁止内联脚本；不渲染原始 HTML | 已实现 |
| T-08 | 恶意整合包 zip 穿越/zip bomb | 覆盖文件/磁盘耗尽 | 实例归档已实现完整校验；通用整合包格式未实现 | 部分（实例归档已防护；natives 已防护） |
| T-09 | 更新包被替换 | 供应链攻击 | 更新模块未实现；设计要求签名验证，未配置公钥则禁用 | 未实现 |
| T-10 | 依赖供应链漏洞 | RCE/数据泄露 | 锁定版本；计划接入 cargo-audit/npm audit | 部分（锁文件） |
| T-11 | 本地缓存损坏 | 启动失败 | 完整性检查 + 重新下载；原子写入避免半文件 | 已实现 |
| T-12 | 恶意 Java 可执行文件 | 用户主动选择的风险 | 仅显示路径与版本，不自动下载/执行未知二进制；启动前明示 | 部分 |
| T-13 | 日志/诊断泄露路径与用户名 | 隐私 | 导出前预览 + 脱敏；默认不上传 | 部分（脱敏函数已实现） |
| T-14 | 服务端 DDoS | 服务不可用 | 本地优先；官方源直连；有限并发与退避；不无限重试 | 已实现（客户端侧） |

## 4. 关键实现约束

- **不使用** `sh -c` / `cmd /C` 拼接启动命令。
- **不记录**完整启动参数（含 accessToken）；只记录脱敏后的摘要。
- **不实现**"假装登录成功"的路径；无凭据时返回 `AUTH_NOT_CONFIGURED`。
- **不把** SHA-1 当作来源可信证明：它只验证与元数据一致；元数据本身通过 HTTPS 官方源获取。
- **不自动**删除用户文件；损坏文件仅报告，重装时覆盖前保留 `.bak`（后续阶段）。

## 5. 剩余风险

1. 官方源被入侵时，哈希校验无法提供额外保护（超出客户端能力）。
2. 用户手动选择恶意 Java 可执行文件，启动器无法完全防御。
3. WebView 0day 不在本项目控制范围内，依赖系统更新。
4. 尚未做模糊测试与第三方渗透测试。
5. 尚未接入自动化依赖漏洞扫描。
