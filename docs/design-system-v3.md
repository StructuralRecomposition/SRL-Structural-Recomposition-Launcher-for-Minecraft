# SRL Design System v3 — Structural

SRL 的界面语言在 v0.2.5 之后进行一次系统性重构。目标不是“换一套颜色”，而是让启动器像一款经过长期维护的桌面工具：信息优先、层级清楚、装饰克制、交互安静。

视觉实现集中在 `src/styles/redesign.css`，在现有 `src/styles.css` 之后加载。旧样式保留为页面结构与历史兼容层；新的颜色、字体、间距、圆角、组件与动效以本文件为准。

## 1. 设计原则

1. **一个页面只有一个视觉重点。** 首页是当前实例与启动按钮；版本页是列表；资源页是搜索与结果。
2. **容器只在需要表达分组时出现。** 首页不再用卡片包裹启动区、日志与活动；实例管理改为列表行；设置页合并为一个分组面板。
3. **深度来自层级，不来自阴影。** 浅色主题用白色表面 + 中性画布；深色主题用两级中性灰。阴影只用于浮层。
4. **强调色只做信号。** 青绿色只用于主操作、焦点、运行状态和选中态；不大面积铺渐变。
5. **字体承担层级。** 页面标题、区块标题、正文、辅助信息、代码/路径各有固定字号与字重，避免整页粗体。
6. **动效回答操作。** 只保留页面进入、浮层出现、按压反馈和进度变化；尊重 `prefers-reduced-motion`。

### 2.2 字体

系统原生字体栈：`-apple-system / SF Pro Text / Segoe UI Variable / PingFang SC / Microsoft YaHei / Noto Sans CJK SC`。等宽字体用于版本号、路径、任务 ID、日志与代码。

| 角色 | 字号 | 字重 | 说明 |
|---|---|---|---|
| 页面标题 | 23px | 640 | `.toolbar h2`，负字距 |
| 首页实例标题 | 30px | 640 | `.launch-panel__identity h2` |
| 浮层标题 | 15px | 620 | `.modal__header h2` |
| 区块标题 | 13px | 600 | `.card-head h3` |
| 正文 | 13px | 400 | `body` |
| 辅助信息 | 11.5–12px | 400 | `.muted` / 描述 |
| 微标签 | 9.5–10.5px | 600 | 大写间距仅用于真正的元信息 |
| 数字 / 路径 | 11–12px | 400–500 | `font-variant-numeric: tabular-nums` |

### 2.3 间距、圆角、层级

- 间距阶梯：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40`
- 圆角：`4`（标签）/ `6`（按钮、输入）/ `8`（面板内元素）/ `10`（卡片）/ `14`（对话框）
- 阴影：默认无；浮层 `0 12px 32px rgba(0,0,0,.12–.4)`；模态 `0 18px 48px`
- 动效：`90ms` 状态反馈、`140ms` 浮层/菜单、`200ms` 页面与模态；缓动以 `ease-out` 为主

## 3. 组件规范

- **Button**：30px 高，6px 圆角，12px 字号；主按钮使用 accent；危险操作使用描边 + 危险色文字。
- **IconButton**：26px 方形，默认低对比，悬停/聚焦时提亮；实例行内的次要操作收进菜单。
- **Menu**：通过 Portal 渲染，避免表格/列表的 `overflow` 裁剪；支持 Escape、点击外部、滚动关闭。
- **Input / Select / Textarea**：30px 高，1px 边框，聚焦时 3px accent 光环。
- **Switch / Checkbox / Radio**：统一 14px 控件；开关 32×18。
- **Tabs / Segmented**：2px 内边距、6px 圆角；激活项使用表面色而不是高饱和填充。
- **Badge**：18px 高，4px 圆角，语义色仅用于状态。
- **Card**：10px 圆角、1px 边框、16px 内边距、无阴影。列表型页面使用单一面板 + 分隔线，而不是卡片网格。
- **Modal**：Portal 到 `body`，`520px`（宽版 `760px`），最大高度 `86vh`；焦点在打开时进入第一个输入。
- **Toast**：右下角，330px，进入 200ms；不阻塞操作。
- **Empty / Notice / Progress**：统一低对比表面 + 语义色左边线；进度条只用 accent。

## 4. 页面重构

| 页面 | 主要变化 |
|---|---|
| 首页 | 启动区改为单一 `launch-panel`：实例身份、启动按钮、四项运行信息；日志与最近活动改为双栏工作台，不再嵌套卡片；空状态改为三步安装清单。 |
| 游戏实例 | 卡片网格改为列表行：身份、6 项元信息、路径、启动/设置/更多菜单；8 个图标操作收进可访问菜单。 |
| 版本管理 | 页头文案收敛；扁平标签页；版本行保持表格化密度。 |
| 资源 | 收紧搜索区高度；来源、搜索、版本、加载器、标签分层；标签横向滚动，结果更早出现。 |
| 设置 | 多个卡片合并为一个分组面板，用分隔线划分“游戏与下载 / 网络与来源 / 联机 / API / 隐私”；右侧路径栏保持粘性。 |
| Java | 环境列表改为行式布局；安装卡与手动路径卡保持清晰分区。 |
| 账号 | 账号行式列表；皮肤与 Microsoft 登录分区保留。 |
| 任务 | 任务列表改为分组面板；速度/剩余/进度收为一行元信息。 |
| 诊断 | 三张摘要卡改为三列网格；检查项使用紧凑分隔列表。 |
| 联机 | 主/侧两栏；状态、房间、日志、成员使用统一面板；模式切换保持在页头右侧。 |
| 鸦鸭 | 对话区改为“角色标签 + 无气泡正文”；用户消息使用轻量表面；输入区固定在底部。 |
| 弹窗 / 菜单 / Toast | 统一圆角、阴影、进入动画与键盘行为。 |

### 设置页信息架构

设置页改为单列、`820px` 内容宽度，默认只展示“游戏与下载”。以下内容使用可折叠分组，避免首屏堆叠：

- 下载与皮肤
- 网络与来源
- API 与集成（52FRP / CurseForge / DeepSeek，各自独立展开）
- 数据与存储（路径、隐私与清理）

## 5. 交互改进

- 按压缩放 `scale(.985)`，只作用 `:active`；悬停不再位移。
- 所有可聚焦元素使用 accent 光环；键盘 Tab 顺序保持不变。
- 实例“更多操作”菜单：Portal、点击外部关闭、Escape 关闭并归还焦点。
- 模态 Portal 到 `body`，避免页面 `transform` 导致 fixed 定位偏移；覆盖整个窗口。
- 加载中的骨架屏与不确定进度保留；移除进度条上的装饰性扫光。
- `prefers-reduced-motion: reduce` 下关闭所有非必要动画。
- 设置中的 API 配置收进可折叠分组；导入实例使用原生文件选择器并自动检查归档。
- 启动时静默检查 GitHub 最新 Release；有更新时弹窗，可经镜像下载、校验 SHA-256 后安装并重启。

## 8. 已知限制

- 旧 `styles.css` 仍包含大量历史页面结构规则；本次通过后置 `redesign.css` 统一视觉。后续可以按页面逐步删除被覆盖的规则。
- Microsoft 登录的 Azure client id 仍是既有能力边界，未在本次 UI 重构中改变。
- 首次进入设置页时 macOS 可能弹出钥匙串授权对话框；这是系统凭据库行为，不是界面层错误。
- 截图中的实例、账号与日志来自本机真实测试数据。
